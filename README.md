# LCARS TNG Theme for TURZX 3.5" Display

Star Trek: The Next Generation inspired LCARS theme for the original TURZX software and AIDA64 sensor integration.

## Overview

This project brings the iconic LCARS (Library Computer Access/Retrieval System) interface from Star Trek: The Next Generation to the TURZX 3.5" USB Display.

Designed specifically for the original TURZX software, the theme uses AIDA64 sensor data to display real-time system information in a clean and authentic TNG-style layout.

Perfect for Star Trek fans who want their PC monitoring display to look like it belongs on the bridge of a Federation starship.

## Features
Authentic LCARS Design
TNG-inspired layout

Design Goals

The objective of this project was not merely to create a "Star Trek themed" display, but to recreate the visual language of LCARS as seen throughout Star Trek: The Next Generation, Deep Space Nine, and Voyager.

Special attention was given to:

Screen proportions
Color balance
Typography
Information density
Usability on a small 3.5" display
Compatibility

Tested with:

Windows 10
Windows 11
Original TURZX Software
AIDA64 SensorPanel Data

Other software combinations may work but have not been verified.
